INFINITY LOAN SERVICES – UPDATED WEBSITE

LOCAL OPENING (Windows)
1. Extract this ZIP into one folder.
2. Keep the assets folder in the same folder as the HTML files.
3. Double-click index.html to open the home page.
4. Navigation links now use local .html filenames, so Join Us, Refer and Earn, Contact Us, About Us and other pages can open locally.

RECOMMENDED LOCAL SERVER
For best results (especially forms and API features), open the folder in VS Code and use the Live Server extension. Right-click index.html and select “Open with Live Server”.

VERCEL DEPLOYMENT
Upload the contents of this folder to the root of your existing Vercel/GitHub project. Keep vercel.json and all assets. The Vercel rewrite configuration supports clean routes.

NOTE
Some server-side/API features require deployment on Vercel and valid environment variables. A local file:// preview cannot run serverless API routes.
